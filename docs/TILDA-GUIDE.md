# Гайд: перенос макета в Tilda

Пошаговый план для человека, который не работал с Tilda раньше.

## 1. Открыть макет как референс

Откройте `mockups/solandsea-mockup.html` в браузере (двойной клик по файлу)
и держите его открытым во вкладке рядом с редактором Tilda — это ваш
визуальный ориентир.

## 2. Создать проект и страницу

1. В Tilda: **Projects → Add Project** → назвать проект `SolAndSea`.
2. Внутри проекта: **Add Page** → пустая страница.
3. В настройках страницы включить **Zero Block** — он даёт больше свободы в
   расположении и стилях, чем стандартные блоки.

## 3. Собирать секции по порядку

Для каждой секции макета — свой блок Tilda. Рекомендуемый порядок и что
использовать:

| Секция макета | Что делать в Tilda |
|---|---|
| Header | Блок типа "Menu" (T001–T005) — вставить пункты меню и кнопку из `SITE-CONTENT.md` |
| Hero | Обложка с галереей фотографий — см. отдельный раздел «3.1» ниже |
| Cómo funciona | Блок "3 колонки с иконками/номерами" (Zero Block → Columns) |
| Para hoteles / Para atracciones | Zero Block с двумя переключаемыми группами, или просто два блока подряд с подзаголовками "Para hoteles" / "Para atracciones" (если табы делать сложно — на первой версии проще сделать статично, без переключения) |
| Excursiones | Блок "Cards"/"Grid" — 3 карточки, фото берутся из `assets/hero/exc1–exc3.jpg` |
| Cómo empezar | 2 колонки с текстом и кнопкой на форму |
| Contacto | Блок "Form" — поля: Nombre, Empresa, Email, Mensaje + выбор Hotel/Atracción |
| Footer | Стандартный Footer-блок Tilda |

## 3.1 Hero: галерея фотографий с поиском

Самая нестандартная часть макета. Порядок сборки:

1. **Фотографии.** Взять четыре файла из `assets/hero/` и загрузить в Tilda
   (Image Storage). Порядок важен — подпись должна совпадать с фото:
   Alicante → Elche → Torrevieja → Mar Menor.
2. **Слайд-шоу на всю ширину.** В библиотеке блоков выбрать раздел
   *Обложка (Cover)* и вариант с несколькими фотографиями / слайдером
   (в Tilda это «обложка со слайд-шоу»). Настройки:
   - высота — 90–100vh;
   - смена слайдов — 5 секунд, эффект — плавное затухание;
   - затемнение фото (Overlay/Затемнение) — около **45–55%**, иначе белый
     текст на светлых фото (Elche) читается плохо.
   Если в тарифе нет слайдера в обложке — поставить одну фотографию
   (`01-alicante.jpg`) и подпись `Alicante`, галерею добавить позже.
3. **Текст по центру.** Только один заголовок из `SITE-CONTENT.md`,
   выравнивание по центру, цвет белый, чуть выше середины экрана.
4. **Поисковая строка.** Стандартного блока «поиск по экскурсиям» в Tilda
   нет, поэтому:
   - самое простое — Zero Block: прямоугольник со скруглением 999px, белая
     заливка, внутри текст-плейсхолдер и кнопка «Buscar» с градиентом
     бренда; вся фигура — ссылка на секцию `#excursiones`;
   - если нужен настоящий поиск — блок поиска по сайту (Search) из
     библиотеки Tilda, оформленный теми же цветами.
   Панель подсказок из макета в Tilda не собирается штатно — на первой
   версии её можно не делать, список направлений уже есть в каталоге.
5. **Две кнопки-двери** под поисковой строкой: «Soy hotel» и «Soy
   atracción» — полупрозрачная белая заливка с обводкой, ведут в секцию
   «Para quién trabajamos».
6. **Подпись места справа снизу.** В Zero Block поверх обложки: мелкий
   заголовок `En la foto` и название места крупным serif-шрифтом,
   выравнивание по правому краю, отступ снизу ~80px. Если слайдер меняет
   фото — подпись придётся либо вынести в саму картинку (вписать текст в
   фото при подготовке), либо оставить статичной для первого фото.
7. **Волна-разделитель** — картинка-разделитель внизу обложки (SVG из
   макета) либо блок-разделитель Tilda с волной, цвет заливки — фон
   следующей секции (`#eef2f1`).

## 4. Цвета и шрифты

1. **Settings → Styles → Colors** — задать палитру из `DESIGN.md` (акцент
   `#1c8a86`, фон `#eef2f1`, текст `#122029`).
2. **Settings → Fonts** — заголовки: Georgia или PT Serif; текст: Roboto или
   Open Sans (ближайшие аналоги к макету, см. `DESIGN.md`).
3. Для градиентных плейсхолдеров: в настройках фона блока/изображения
   выбрать **Gradient** и ввести четыре цвета из `DESIGN.md`
   (`#c0466b → #e08a3f → #1c8a86 → #1d4d84`), направление — сверху вниз под
   углом (в макете это 160°).

## 5. Двуязычность (ES/EN)

Tilda не переключает язык на одной странице так же гибко, как в макете
(там это JS). Два практичных варианта:

- **Проще для старта:** одна страница на испанском (основной рынок), плюс
  отдельная страница `/en` с полной англоязычной копией. Добавить в шапку
  ссылку-переключатель `ES / EN`, ведущую на другую страницу.
- **Через Tilda Multilang** (если подключён на тарифе): встроенный модуль
  мультиязычности — переключатель языка в шапке настраивается автоматически.

Тексты для обеих версий уже готовы построчно в `SITE-CONTENT.md`.

## 6. Форма заявки

1. Добавить блок "Form".
2. Поля: Nombre/Name (текст), Empresa/Company (текст), Email, Mensaje/Message
   (текстовая область), выбор Hotel/Atracción (radio или select).
3. В настройках формы подключить получение заявок на email
   (**Content → Form settings → Send to email**) — адрес
   `doremisolandsea@gmail.com`.

## 7. Проверка перед публикацией

- [ ] Все тексты вставлены из `SITE-CONTENT.md`, опечаток нет
- [ ] Кнопки CTA ведут на форму (`#contacto`)
- [ ] Цвета и шрифты соответствуют `DESIGN.md`
- [ ] Форма отправляет заявку на реальную почту
- [ ] Сайт проверен на мобильном виде (Tilda: переключатель Desktop/Tablet/Mobile)
- [ ] Домен подключён (**Settings → Domain**)

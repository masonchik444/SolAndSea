# Бриф проекта

## Что за компания

**SolAndSea** — B2B-туроператор на старте, работает в Аликанте (Коста-Бланка,
Испания). Модель:

1. Компания связывается с туристическими объектами региона (музеи,
   достопримечательности, крепости и т.д.) и договаривается о ценах.
2. Из этих договорённостей собираются готовые экскурсионные программы.
3. Программы предлагаются отелям, которые продают их своим гостям —
   отель получает комиссию/доп. доход, ничего не организуя сам.

Источник вдохновения по подаче — [Tripster](https://experience.tripster.ru/)
(но Tripster — B2C-платформа для конечных туристов; SolAndSea работает с
двумя B2B-аудиториями: отелями и туробъектами).

## Аудитории сайта

Две аудитории на одной странице (см. `docs/DESIGN.md` про табы):

- **Отели** — им нужно понять выгоду (доп. доход, ноль логистики) и оставить
  заявку.
- **Туристические объекты/атракции** — им нужно понять выгоду (поток
  туристов от сети отелей) и оставить заявку на партнёрство.

## Регион запуска

Аликанте, Испания. Сайт двуязычный: **испанский (по умолчанию) + английский**.
Примеры экскурсий на старте: Castillo de Santa Bárbara, Casco Antiguo
(Barrio de Santa Cruz), MARQ (Museo Arqueológico de Alicante).

## Технология сайта

Сайт собирается в **Tilda** конструктором (не кодом). Этот репозиторий хранит
контекст для сборки: дизайн-макет как визуальный референс, готовые тексты
для копирования в блоки, и гайд по переносу в Tilda.

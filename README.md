# SolAndSea

B2B-туроператор в Аликанте (Коста-Бланка). Мы договариваемся с музеями и
достопримечательностями о ценах на экскурсии, собираем из них готовые
программы и предлагаем отелям продавать их своим гостям — без посредников
и без затрат отеля на организацию.

Сайт — одна статическая страница в папке `public/`, публикуется на
[Cloudflare Pages](https://pages.cloudflare.com/) на домене
**doremisolandsea.com**. Репозиторий хранит и сам сайт, и рабочий контекст
проекта: бриф, тексты в двух языках, дизайн-систему и инструкции.

## Структура репозитория

```
.
├── public/                  # Сам сайт — то, что публикуется на домене
│   ├── index.html           # Единственная страница (ES/EN)
│   ├── og.jpg               # Картинка для превью ссылки
│   ├── favicon.svg
│   └── assets/hero/         # Фотографии галереи, карточек и вкладок
└── docs/                    # Контекст проекта: бриф, тексты, дизайн, публикация
    ├── PROJECT-BRIEF.md
    ├── DEPLOY.md
    ├── PHOTOS.md
    ├── SITE-CONTENT.md
    ├── PARTNER-OUTREACH.md
    ├── DESIGN.md
    └── TILDA-GUIDE.md
```

## С чего начать

1. Прочитать [`docs/PROJECT-BRIEF.md`](docs/PROJECT-BRIEF.md) — что за
   компания, для кого сайт, какие есть открытые вопросы.
2. Открыть [`public/index.html`](public/index.html) в браузере — это сам
   сайт (ES/EN, светлая/тёмная тема).
3. Публикация на домене — по шагам из [`docs/DEPLOY.md`](docs/DEPLOY.md)
   (Cloudflare Pages + Namecheap).
4. Тексты сайта построчно — в [`docs/SITE-CONTENT.md`](docs/SITE-CONTENT.md),
   палитра и типографика — в [`docs/DESIGN.md`](docs/DESIGN.md).
5. Для выхода на туристические объекты взять готовые письма и скрипты из
   [`docs/PARTNER-OUTREACH.md`](docs/PARTNER-OUTREACH.md).

# SolAndSea

B2B-туроператор в Аликанте (Коста-Бланка). Мы договариваемся с музеями и
достопримечательностями о ценах на экскурсии, собираем из них готовые
программы и предлагаем отелям продавать их своим гостям — без посредников
и без затрат отеля на организацию.

Сайт компании делается на [Tilda](https://tilda.cc/). Этот репозиторий —
не исходный код сайта (Tilda не работает с git), а рабочий контекст проекта:
дизайн-макеты, тексты и документация, которые используются при сборке
страниц в конструкторе.

## Структура репозитория

```
.
├── mockups/                 # HTML-превью дизайна (референс перед переносом в Tilda)
│   └── solandsea-mockup.html
└── docs/                    # Контекст проекта: бриф, тексты, дизайн, гайд по Tilda
    ├── PROJECT-BRIEF.md
    ├── SITE-CONTENT.md
    ├── DESIGN.md
    └── TILDA-GUIDE.md
```

## С чего начать

1. Прочитать [`docs/PROJECT-BRIEF.md`](docs/PROJECT-BRIEF.md) — что за
   компания, для кого сайт, какие есть открытые вопросы.
2. Открыть [`mockups/solandsea-mockup.html`](mockups/solandsea-mockup.html)
   в браузере — это визуальный черновик лендинга (ES/EN, светлая/тёмная тема).
3. Взять готовые тексты из [`docs/SITE-CONTENT.md`](docs/SITE-CONTENT.md) и
   вставить их в блоки Tilda по шагам из
   [`docs/TILDA-GUIDE.md`](docs/TILDA-GUIDE.md).
4. Держаться палитры и типографики из [`docs/DESIGN.md`](docs/DESIGN.md),
   чтобы сайт в Tilda выглядел так же, как макет.

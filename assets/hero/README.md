# Фотографии для галереи на главной

Галерея в hero-секции макета (`mockups/solandsea-mockup.html`) листает четыре
фотографии, и вместе с ними меняется подпись места справа снизу.

Положите файлы в эту папку **ровно с такими именами** — макет подхватит их
автоматически:

| Файл | Что на фото | Подпись в макете |
|---|---|---|
| `01-alicante.jpg` | Винодельня (Pepe Mendoza, Alicante) | **Alicante** |
| `02-elche.jpg` | Пальмовый сад / Huerto del Cura | **Elche** |
| `03-torrevieja.jpg` | Закат на воде, сваи | **Torrevieja** |
| `04-mar-menor.jpg` | Закат над лагуной и посёлком | **Mar Menor** |

## Требования к файлам

- Формат: JPG (или WebP — тогда поменяйте расширение в `--photo:url(...)`
  внутри `mockups/solandsea-mockup.html`, блок `.hero-gallery`).
- Ширина: **не меньше 1920 px**, лучше 2400 px — фото открывается на весь
  экран.
- Вес: до ~400 КБ на файл после сжатия (например,
  [squoosh.app](https://squoosh.app/)) — иначе главная будет грузиться долго.
- Кадр: важное — по центру и сверху; низ кадра перекрывается затемнением,
  подписью места и волной-разделителем.

## Пока фото не добавлены

Каждый слайд имеет запасной градиент в цветах своей фотографии
(`--fallback` в атрибуте `style`), поэтому макет корректно открывается и без
картинок — просто вместо фото видны цветные заливки.

## Порядок и количество

Слайдов может быть больше или меньше четырёх. Чтобы добавить слайд, нужно
синхронно добавить три вещи в `mockups/solandsea-mockup.html`:

1. `<div class="hero-slide" …>` в блоке `.hero-gallery`;
2. `<b>Название</b>` в `.hero-place` — подпись справа снизу;
3. `<button … onclick="setSlide(N, true)">` в `.hero-dots` — точку-индикатор.

Порядок элементов в этих трёх списках должен совпадать: слайд 1 ↔ подпись 1 ↔
точка 1.
